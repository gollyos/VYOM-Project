# Morning Briefing

The Phase 7 morning briefing is assembled from current local CRM, local drafts, durable automations, pending task approvals, and health-checked external integrations.

Every source has an observed timestamp, status, and detail. If email or calendar is disconnected, the briefing is marked partial and the related value is unavailable—not zero and not a historical mock. Connected calendar events are counted only from the provider response.

The response summons a status summary, source-health evidence, and any relevant approval surface around the Living Core. It does not open a dashboard or persist a card grid. `Show agency` similarly recomposes the same canvas from CRM counts and explicit integration health.

The first priorities are derived from actual pending approvals, local drafts, and qualified CRM leads. If none exist, VYOM states that no locally verified urgent work is recorded.
